SOLE Software User Guide 

SOLE consists of four modules: (1) Home: A welcome page; (2) Design: A simple lidar hardware system setup module designed to help users understand the composition of lidar hardware; (3) Parameters: Lidar simulation parameter settings, which form the core of the SOLE; (4) Processing: Data processing for displaying simulation results. Currently, only specific sample files can be displayed, and its use is not recommended. Users are advised to plot simulation data using other software. The following section focuses on module (3), parameter settings.
The Parameter module includes the hardware parameters section on the left, the simulation parameters section in the middle, and the atmospheric and oceanic parameters section on the right. To perform a simulation, users first need to configure the lidar system parameters. The transmitter parameters include laser wavelength, satellite altitude, pulse width, number of photons, laser divergence angle, and initial Stokes vector. The receiver parameters include telescope field of view, diameter, detector bandwidth, atmospheric statistical resolution, and seawater statistical resolution.
On the right side of the Parameter module is the critical atmospheric and oceanic parameter settings section. The Atmosphere section supports two parameter configuration methods: a single atmospheric medium layer, where users can directly select the layer type, particle number concentration, layer thickness, and layer top height on the page; and a multi-layer input mode. By clicking the Atmosphere button, a Custom Parameters dialog box will pop up, allowing users to set the total number of layers and the parameters for each layer. After configuration, click the OK button in the top-right corner. This mode is suitable for spaceborne scenarios with multiple atmospheric layers.
The Ocean section is similar. For homogeneous seawaters, users can select from several built-in parameters and scattering phase functions and set the maximum depth. For inhomogeneous seawaters, users need to click the top Ocean button and configure the parameters for each layer in the Custom Parameters dialog box. For the sea surface, wind speed must be specified. Additionally, in polarized lidar mode, the normalized Mueller matrix parameters for seawater need to be set.
In the simulation parameter settings section in the middle, users must first select the lidar's operational mode. To save simulation time, the software provides three built-in programs: non-polarized elastic scattering lidar, polarized lidar, and standalone rough sea surface simulation. The polarized lidar mode corresponds to the program described in the SOLE paper. Below, our contact information and the personal website of the contact person are provided.
Additionally, the software supports both CPU and GPU hardware simulations. When selecting the CPU option, users need to set the number of synchronous threads. After all parameters are configured, click the green Start button to begin the simulation. Once the program starts running, the progress will be displayed in the progress bar at the bottom. When the progress reaches 100%, the simulation is complete. To stop the simulation midway, users can click the red Finish button. The simulation results are saved in the "signal" folder within the original directory where SOLE is located.
